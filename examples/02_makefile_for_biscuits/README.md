# Makefiles for multiple file builds.

This is where Makefiles really shine. They can be used to build multiple files into a single executable. This is a very common use case, and is the reason why Makefiles are so widely used in the C/C++ world.

We have two versions of the Makefile here. The first is a simple version that is easy to understand, but not very flexible. The second is a more complex version that is more flexible, but harder to understand.

You can run either of them with (say):

```bash
make -f Makefile.simple
```
